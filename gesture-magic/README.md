# 秘境召唤 · ARCANUM — 手势召唤粒子魔法

这是一个网页摄像头互动程序：用 MediaPipe 识别手势，然后在你的手上召唤火焰、星尘、闪电、黑洞和等离子核。所有特效都用 Canvas 实时绘制，背景音乐和音效全部由 Web Audio 实时合成，不需要任何素材文件。

## 运行

摄像头只能在 `localhost` 或 `https` 下打开：

```bash
cd gesture-magic
python3 -m http.server 8000     # 或 npx serve .
# 浏览器打开 http://localhost:8000
```

点「唤醒」后允许摄像头权限。建议戴耳机。没有摄像头时可以选「以鼠标施法」。

## 法术表

| 手势 | 法术 | 效果 |
|---|---|---|
| 👆 只伸食指 | **焚星** | 指尖燃起火球，带火星和余烬拖尾，周围的环境被火光照亮，有火焰低吼和噼啪声 |
| ✌️ 剪刀手 | **星尘** | 两根指尖拖出星光丝带，粒子之间自动连成星座线，移动时有细碎的钟声 |
| 🤘 摇滚手势 | **雷殛** | **四处放电**：闪电从指尖劈向屏幕四周、地面、漂浮光点和另一只手，光点之间还会连锁放电。电流会在整只手的骨骼上流动，闪电照亮整个房间，伴随持续的**滋滋**电流声和噼啪爆裂声 |
| ✋ 张开手掌 | **破界** | 掌心爆出冲击波、放射状闪电和粒子；手掌一直张开时，掌心会出现旋转的符文法阵 |
| ✊ 握拳 → ✋ 张开 | **蓄能 / 星爆** | 握拳时四周的能量被吸进拳心，伴随上升音和震屏；张开手后释放的星爆威力与蓄力时长成正比 |
| 👌 拇指食指捏合 | **黑渊** | 生成一个黑洞，带吸积盘和光子环，会把画面上所有粒子卷进去 |
| 👆👆 双手食指相对 | **紫晶核** | 两指之间凝聚一颗等离子球，电弧连着指尖，球的大小随双手距离变化 |
| 紫晶核存在时张开手掌 | **天崩** | 全屏级大爆炸 |

## 快捷键

`M` 静音　`B` 显示/隐藏手部骨骼　`H` 隐藏界面　`F` 全屏　鼠标模式下按 `1–7` 切换法术，按住鼠标蓄力，松开释放星爆。

## 声音设计（全部程序化合成）

- **配乐**：低频 drone（锯齿波 + 缓慢扫动的低通滤波）、幽谷风声、D 弗里几亚属音阶上的和弦铺底与随机钟声（带延迟和混响）、缓慢的心跳低音。施法越激烈，滤波开得越大，节奏也越密。
- **滋滋电流**：高频带通噪声，每帧随机门控并抖动中心频率，叠加经过失真的 100Hz 蜂鸣。每道闪电还会单独触发一次爆裂声，偶尔带出远处的雷鸣。
- 其他音效：火焰、等离子嗡鸣、黑洞涡流、蓄能上升音，以及爆炸（噪声扫频、次低频下坠和钟声余韵）。

## 技术

- 手势识别使用 `@mediapipe/tasks-vision` HandLandmarker（最多 2 只手，GPU 加速，失败时自动退回 CPU），完全在本地运行，画面不会上传。
- 页面是单个 HTML 文件，没有构建步骤。
