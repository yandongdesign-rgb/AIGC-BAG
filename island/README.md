# 🏝 潮汐之岛 · Tide Island

一座可以用**手势**漫游的、会“呼吸”的 3D 热带海岛（纯前端：Three.js + MediaPipe + WebAudio，无需任何素材文件，全部程序化生成）。

## 运行

摄像头只能在 **https** 或 **localhost** 下使用，因此请用本地服务器打开：

```bash
cd island
python3 -m http.server 8080      # 或 npx serve .
# 浏览器打开 http://localhost:8080
```

首次进入手势模式会从 CDN 下载手势识别模型（约 8MB）。不开摄像头也可以用键鼠 / 触屏模式游玩。

## 世界里有什么

| 类别 | 内容 |
| --- | --- |
| 昼夜 | 24 小时循环（现实 20 分钟一天，可 8×/60× 加速）：日出、正午、晚霞、日落、星空与银河、月亮、流星 |
| 天气 | 晴朗 / 多云 / 乌云密布 / 下雨 / 暴风雨 / 海雾，自动马尔可夫切换或手动指定；风力影响树木摇摆、海浪高度、云速、雨丝倾斜；暴风雨有闪电与按距离延迟的雷声；雨后背对太阳会出现**彩虹** |
| 地形 | 沙滩、热带丛林、北侧高耸的海崖（东侧有缓坡可登顶俯瞰全岛），崖壁下有**可避险的山洞**（洞里不下雨、风雨声变闷、有篝火与发光水晶、钟乳石） |
| 海洋 | Gerstner 波浪、浅水透明见底、岸边浪花与泡沫、阳光反射、风暴时白浪 |
| 植物 | 椰子树（树上挂着椰子）、芭蕉、蕨类、扶桑花、草丛、丛林树，全部随风摆动 |
| 生物 | 横着走的螃蟹（靠近会逃、下雨会钻沙、坐下不动它们会靠近）、盘旋/落地/被惊飞的海鸥、跃出水面的鱼与远处的海豚、白天的蝴蝶、夜晚的萤火虫 |
| 物品 | 扇贝壳、海螺、海星、扁平鹅卵石、椰子、浮木、漂流瓶（里面有信）、螃蟹——都可以捡起、收进背包、取出、扔出去 |
| 声音 | 生成式背景音乐（尤克里里扫弦、卡林巴旋律、柔和铺底与贝斯，随白天/夜晚/风暴变换情绪）+ 海浪、风、雨、虫鸣、鸟鸣、篝火噼啪 + 各种拾取/投掷/落水/脚步音效 |

## 手势操作（摄像头）

| 手势 | 作用 |
| --- | --- |
| 🖐 张开手掌 | 前进；手偏左/右 = 转向，偏上/下 = 抬头/低头 |
| 🖐🖐 双手张开 | 奔跑 |
| ☝️ 食指 | 用指尖瞄准 / 原地转头 |
| 🤏 捏合 或 ✊ 握拳 | 拾取准星下的物品（对着椰子树 = 摇树） |
| 拿着物品时张开手并**向前甩** | 投掷（甩得越快扔得越远；慢慢张开 = 轻轻放下） |
| ✌️ 剪刀手 | 拍照（左下角可下载） |
| 👍 点赞 | 跳跃 |
| 👎 倒赞 | 把手中物品收进背包；空手时坐下休息（时间加速） |
| 🤟 摇滚手势 | 使用：吹海螺 / 听贝壳 / 喝椰子 / 读漂流瓶 / 放生螃蟹 / 浮木画爱心 / 生火添柴 / 吹口哨唤海鸥 |

## 键鼠 / 触屏

WASD 移动 · Shift 奔跑 · 鼠标视角（点击画面锁定）· 空格 跳 · 左键拾取，拿着时**按住左键蓄力、松开投掷** · 右键/G 放下 · E 使用 · Q 收进背包（空手=坐下）· C 坐下 · P 拍照 · 1–6 切换天气 · 0 自动天气 · T 时间流速 · M 音乐开关 · Tab 设置面板 · H 帮助。触屏设备会显示虚拟摇杆与按钮。

## 一些可以尝试的事

- 把**扁石头/贝壳**低角度用力扔向海面——**打水漂**，看能跳几下
- 用石头**砸椰子树**，椰子会掉下来；喝一口椰子汁
- 暴风雨来时躲进**北面崖壁下的山洞**，用一根浮木**点燃篝火**
- 在沙滩上**坐下**，等螃蟹爬到你身边
- 吹响海螺，海鸥会飞来盘旋
- 捡起漂流瓶读信，再把它扔回大海
- 雨停后背对太阳找**彩虹**，日落时拍一张照片；夜里抬头看星空与流星
- 解锁各种成就 🏅

## 代码结构

```
island/
├─ index.html        HUD、样式、import map
└─ js/
   ├─ main.js        主循环、玩家、输入（手势/键鼠/触屏）、交互、成就、HUD
   ├─ world.js       高度场：海岛、海崖、山洞（洞顶岩块）、地表类型
   ├─ sky.js         天空着色器：昼夜、云层、星空、月亮、彩虹、闪电；太阳/月光
   ├─ ocean.js       Gerstner 波浪海面
   ├─ weather.js     天气状态机、风、雨滴、闪电
   ├─ vegetation.js  程序化植被 + 风吹摇摆着色器
   ├─ items.js       可拾取物品、投掷物理、打水漂、螃蟹 AI
   ├─ creatures.js   海鸥、鱼/海豚、蝴蝶、萤火虫
   ├─ effects.js     水花、沙尘、火焰、波纹、脚印
   ├─ audio.js       WebAudio 生成式音乐、环境声、音效
   ├─ gesture.js     MediaPipe 手势识别与手速估计
   └─ noise.js       Simplex 噪声与工具函数
```
