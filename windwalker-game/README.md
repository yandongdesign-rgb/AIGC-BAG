# 逐风剑客 · 林间试炼

无需安装依赖的浏览器横版动作小游戏，使用 HTML Canvas 和原生 JavaScript 编写。

## 运行

下载 `index.html`，双击并用现代浏览器打开即可。支持电脑键盘和手机触屏按钮。

## 操作

| 动作 | 按键 |
| --- | --- |
| 移动 | A / D 或左右方向键 |
| 跳跃 | 空格 / W / 上方向键 |
| 下蹲躲箭 | S / 下方向键 |
| 挥剑 | J |
| 暂停或继续 | P |

三道关卡依次为翡翠幽林、暮色峡谷、月下古堡。跳过尖刺，下蹲躲避箭矢，击败全部守卫后进入终点。每关开始时恢复五点生命。

## 检查

安装 Node.js 后运行 `node verify.cjs`，检查跳跃落地、下蹲、挥剑命中、受伤保护、箭矢碰撞和三关出口逻辑。该检查使用模拟画布，不代替浏览器实玩验证。
