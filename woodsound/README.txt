木声 WOODSOUND

打开 index.html 即可使用，无构建步骤、无后端和第三方脚本。
固定机身尺寸为 800 × 600 像素，小屏可横向滚动。
录音需要现代浏览器、麦克风权限；本地文件权限受限时可通过 localhost 打开。
录音为当前页面内存数据，关闭前请导出 WAV。每十分钟独立分段，叠加时从起点混音。

验证：app.js 已通过 node --check。尚未进行浏览器视觉、麦克风及十分钟实测。
电台限制：已配置十个公开频道及原生 HLS 分支，但实测两个 MP3 域名的首频道均返回 404。
故电台播放尚未通过验收；自动切台只能处理故障，不能保证源可用。
当前无法声称十个免费 CORS 友好流全部可播放。HLS 需要浏览器原生支持。
频道和源在 app.js 的 stations / hlsNames 中维护。频率仅为地区参考。
源参考：https://www.rhba7jwe.top/radio-livestream/
