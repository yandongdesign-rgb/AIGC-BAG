星耀 KTV · 桌面端卡拉 OK 点歌演唱工具  使用说明
==================================================

一、怎么打开
--------------------------------------------------
1. 直接双击本文件夹里的 index.html，用浏览器打开即可（无需安装、无需服务器、可离线使用）。
2. 推荐浏览器：Chrome / Edge 最新版（电脑桌面端）。Firefox 也可使用。
3. 首次点击「麦克风」时浏览器会询问麦克风权限，请选择「允许」。
4. 建议戴耳机演唱，外放音箱 + 麦克风监听容易产生啸叫/回声。

二、基本操作（与线下 KTV 点歌机一致）
--------------------------------------------------
· 点歌：左侧点歌台搜索（歌名 / 歌手 / 拼音首字母，如“yyjn”=烟雨江南）或按分类浏览，
        点击歌曲卡片或「+」即点歌，加入右侧「已点」列表；没有歌在唱时会自动开始。
· 歌曲卡片按钮：+ 点歌 / ↑ 优先（置顶）/ ▶ 立即演唱 / ♡ 收藏
· 已点列表：优先（置顶）、删除、清空；「已唱」可再点；面板可点击左侧小标签收起/展开。
· 底部控制栏：
    原唱 / 伴唱   —— 两条独立音轨（原唱版、伴奏版）同步播放，一键无缝切换
    上一首 / 重唱 / 播放暂停 / 切歌 / 播放模式（顺序、单曲循环、列表循环）
    调音 ♭ / ♯    —— 降调 / 升调（±6 个半音，只变调不变速），点击中间数字恢复原调
    总音量 / 伴奏音量 / 麦克风音量 三路独立调节，喇叭图标 = 静音
    麦克风 / 监听 / 录音
· 进度条：可点击或拖动跳转，鼠标悬停显示时间。
· 歌词：大屏左下角切换「双行」（KTV 经典上下交替）/「单行」/「滚动」；
        逐字擦色高亮，跟随音乐时间轴；首句和长间奏前有 ●●●● 倒计时。
· 打分：开启麦克风演唱，每句给出 PERFECT / GREAT / GOOD / OK / MISS，整曲结束显示分数 + 星级。
· 背景：右上角「背景」可选霓虹律动动画、动态视频、静态图片、歌曲封面，或上传自己的图片/视频。
· 设置：混响、回声消除/降噪、耳返监听、新歌默认原唱或伴唱、打分开关、歌词字号。
· 快捷键：空格 播放/暂停，N 切歌，R 重唱，V 原唱/伴唱，+/- 升降调，←/→ 快退快进 5 秒，M 静音，F 全屏。

三、录音与下载
--------------------------------------------------
1. 先打开「麦克风」，演唱时点击「录音」，顶部出现红色 REC 计时。
2. 再次点击「录音」或歌曲结束/切歌时自动停止并保存。录音内容 = 你的人声（含混响）+ 伴奏混音，
   与总音量无关（音箱调小也不影响录音音量）。
3. 右侧「录音」标签可在线试听，并可「下载 WAV」（任何播放器都能放）或下载原始 WEBM 格式。
4. 录音保存在本机浏览器里，刷新页面后依然存在。

四、补充 / 替换歌曲
--------------------------------------------------
方式 A：应用内上传（最简单，推荐）
  · 右上角「上传歌曲」→「单首上传」：填写歌名、歌手、分类，选择
        原唱音频（必填）、伴奏音频（独立伴奏音轨，强烈建议提供）、LRC 歌词、封面图片。
  · 「批量导入」：一次多选很多文件，按文件名自动配对，例如：
        周杰伦 - 晴天.mp3          （原唱）
        周杰伦 - 晴天_伴奏.mp3     （伴奏，文件名后缀可用：伴奏 / 伴唱 / 消音 / inst / instrumental / karaoke）
        周杰伦 - 晴天.lrc          （歌词）
        周杰伦 - 晴天.jpg          （封面，可选）
  · 上传的歌曲保存在本机浏览器（IndexedDB），刷新后仍在，可在「我的上传」分类中编辑 / 删除 / 导出。
  · 若没有伴奏文件，系统会用“声道相减”自动生成「消音伴奏」作为备用（效果取决于原曲混音，
    最好还是提供独立伴奏音频）。
  · 支持格式：mp3 / wav / m4a / ogg / flac 等浏览器可解码的格式；LRC 自动识别 UTF-8 / GBK 编码。

方式 B：做成内置歌曲包（换电脑、换浏览器也能用）
  1. 在「我的上传」里点歌曲上的「导出」图标，得到一个 xxx.js 歌曲包文件。
  2. 把它放进 library/songs/ 文件夹。
  3. 用记事本打开 library/manifest.js，在列表里加上一行文件名，例如  "xxx.js",
  4. 刷新页面即可在曲库中看到。
  说明：浏览器禁止本地双击打开的网页直接读取硬盘上的 mp3 路径，所以内置歌曲的音频以 base64
        方式写在 .js 文件中，这样双击 index.html 也能正常进行混音、变调等处理。

方式 C：手写歌曲包（开发者）
  library/songs/ 下每个 .js 文件调用一次 KTV.registerSong({...})，格式参考 library/songs/demo01.js：
    KTV.registerSong({
      id: "mysong01",                 // 唯一 ID
      title: "歌名", artist: "歌手", album: "专辑",
      tags: ["hot", "pop"],           // hot 热门 / pop 流行 / guofeng 国风 / folk 民谣 / oldies 老歌 / english 英文歌
      duration: 215,                  // 秒，可选
      cover: "assets/songs/xxx/cover.jpg",   // 封面：相对路径或 data URL，可选
      lrc: "[00:12.00]第一句歌词\n[00:16.50]第二句歌词",
      original: "data:audio/mpeg;base64,....",      // 原唱
      instrumental: "data:audio/mpeg;base64,...."   // 伴奏（可为 null）
    });

五、LRC 歌词格式
--------------------------------------------------
· 标准格式：[分:秒.百分秒]歌词，例如 [01:23.45]我们说好不再说再见
· 逐字格式（更精准的逐字擦色）：[00:05.22]<00:05.22>晚<00:05.54>风<00:05.87>轻...<00:09.65>
· 支持 [ti:歌名] [ar:歌手] [al:专辑] [offset:+200]（毫秒，正数表示歌词提前）

六、文件夹结构
--------------------------------------------------
index.html                 主页面（双击打开）
css/style.css              界面样式（深色霓虹 KTV 主题）
js/utils.js                通用工具（拼音首字母、本地存储、下载）
js/library.js              曲库模块（内置歌曲包 + 上传歌曲）
js/queue.js                已点队列 / 已唱 / 播放模式
js/lyrics.js               歌词解析（LRC）+ 歌词大屏渲染
js/audio-engine.js         音频控制（原唱/伴奏双音轨、三路音量、麦克风、混响、录音）
js/pitch-shifter.js        升降调（相位声码器，变调不变速）
js/scoring.js              演唱打分
js/background.js           播放背景（动画 / 视频 / 图片）
js/ui.js                   界面模块（点歌台、已点面板、上传/背景/设置弹窗）
js/app.js                  主控制器（串联整个点歌演唱流程）
library/manifest.js        曲库清单（登记 library/songs/ 下的歌曲包）
library/songs/*.js         内置歌曲包（Demo 5 首）
assets/songs/demoXX/       Demo 原始素材：original.mp3 原唱、instrumental.mp3 伴奏、lyrics.lrc、cover.svg
assets/backgrounds/        背景素材（图片 + 循环视频）
tools/generate_demo_assets.py  Demo 素材生成脚本（开发用，普通用户无需运行）

七、常见问题
--------------------------------------------------
· 没有声音：确认系统音量、页面「总音量」未静音；首次需要点击页面任意处以启用音频。
· 麦克风打不开：浏览器地址栏左侧点锁/信息图标 → 允许麦克风；确认电脑已连接麦克风。
· 有回声 / 啸叫：戴耳机，或在「设置」里开启「回声消除/降噪」、关闭「监听」。
· 监听有延迟：浏览器音频链路存在几十毫秒延迟属正常；专业场景建议使用声卡硬件监听，并关闭软件监听。
· Demo 歌曲为程序合成的原创示例曲（合成人声），仅用于功能演示，请替换为你自己的歌曲。
· 清空浏览器网站数据会删除上传的歌曲和录音，重要歌曲建议「导出歌曲包」备份。
