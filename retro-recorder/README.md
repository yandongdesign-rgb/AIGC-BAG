# 木韵 RC-1985 · 复古双卡收录机

一个仿 80 年代台式收录机的网页工具，所有代码都在一个 `index.html` 文件里，只用 HTML、CSS 和原生 JavaScript。不需要构建，也不需要后端，双击就能打开。机身固定 800 × 600，窗口太小时会等比缩小。

## 功能
| 模块 | 说明 |
|---|---|
| 录音 | 按红色 REC 键开始录音。录音时按键闪红光，屏幕上的 VU 表和 LED 电平灯会跟着跳动。每段录到 10 分钟会自动分段保存。播放的同时也能录（叠录）。 |
| 回放 | 拖动磁带进度条可以跳转。◀◀ / ▶▶ 单击跳 5 秒，长按以 8 倍速匀速倒带或快进，松开就停在当前位置，倒带时有变调的走带声。播放速度可选 0.5× / 1× / 1.5×。 |
| 磁带库 | “单段循环”和“多段叠加”两个开关：叠加模式下，勾选的几段会混在一起同时播放。每段都能下载或删除。 |
| 电台 | 内置 10 个央广频道。转动 TUNING 拨盘、滚动滚轮或点击刻度都能换台，屏幕显示台名和频率。RADIO VOL 旋钮单独调电台音量，换台时有沙沙的调谐声。 |
| 外观 | 木纹机身、金属铆钉、细网喇叭罩、透明磁带仓（磁带轮按真实的轮径和转速转动）、黑色调谐拨盘，按键按下有下沉效果和机械声。 |

## 异常处理
- 麦克风权限被拒、没有麦克风、麦克风被占用时，会弹出对应的说明，并提供“重新授权”按钮。
- 电台加载失败时，先换本台的其他线路，再去 Radio-Browser 公共目录按台名找新地址，都不行就自动切到下一个频道。10 个频道全部失败时提示检查网络。
- 录音每 10 分钟自动分段。不在使用中的片段会释放解码后的数据，减少内存占用。

## 快捷键
空格：播放 / 暂停　R：录音　S：停止　P：暂停　按住 ← / →：倒带 / 快进

## 注意
- 录音只保存在当前页面的内存里，刷新或关闭页面就没了，需要的片段请先点 ⤓ 下载。
- 个别浏览器不允许 `file://` 页面使用麦克风，这时可以在本目录运行 `python3 -m http.server`，再打开 http://localhost:8000。
- 电台用的是第三方公开直播流（蜻蜓 FM 的央广转播），地址可能会变，也可能因地区而无法访问。如需修改，编辑 `index.html` 里的 `STATIONS` 数组。浏览器要原生支持 HLS（如 Safari）才会用到 cnr.cn 的线路。电台的 VU 表是模拟的，因为跨域音频流不能接入 Web Audio 分析。
