# 珊瑚湾闲钓 REEF FISHING

直接用新版 Chrome、Edge 或 Safari 打开 index.html。纯 HTML/CSS/JavaScript，无构建步骤、无外部素材，画面用 Canvas 绘制，背景音乐与音效用 Web Audio API 实时合成。标题字体从 Google Fonts 加载，离线时自动回退系统字体。

- 左侧选鱼饵（蚯蚓、面包屑、小虾、甜玉米、亮片），也可按数字键 1–5 切换；不同鱼偏爱不同鱼饵。
- 点击水下任意位置抛竿，点得越深鱼钩沉得越深；空格键随机抛竿。
- 鱼漂轻点是试探，提早提竿会吓跑鱼；鱼漂猛沉时立即点击提竿。
- 按住鼠标（或空格）收线，松开放线；张力满格会断线，线太松鱼会挣脱。
- 9 种鱼：小丑鱼、蓝倒吊、锦鲤、神仙鱼、蝴蝶鱼、河豚、鲈鱼、金龙鱼、蓝鳍金枪鱼，个头越大越难拉。
- 左侧鱼篓展示品种、数量与最大重量，未发现的鱼显示剪影和喜好鱼饵；记录保存在浏览器 localStorage。
- 音乐、音效可分别开关，支持全屏；浏览器要求先点击「开始钓鱼」才能出声。

作为动态桌面：Windows 可用 Lively Wallpaper、macOS 可用 Plash 把 index.html 设为网页壁纸。

验证：Chromium 无头模式完成抛竿、试探、咬钩、提竿、收线和收入鱼篓的完整流程；无页面脚本错误。未在真实扬声器上试听音频。
