# 木声 WOODSONIC

直接用新版 Chrome、Edge 或 Safari 打开 index.html。纯 HTML/CSS/JavaScript，无构建步骤和后端，机身固定 800 × 600。首次录音需要允许麦克风；部分浏览器限制 file:// 麦克风，可使用本地静态服务器打开。

- REC 开始/结束录音，STOP 保存并停止；每 10 分钟自动分段继续录制。
- 点击磁带条目选段，↓ 下载原始录音；刷新页面将清除临时录音。
- PLAY 回放，PAUSE 暂停；拖动进度跳转；长按 REW / FF 匀速走带，松开停在当前位置。
- 支持 0.5× / 1× / 1.5×、单段循环、多段从起点同步叠加。
- 拖动调谐旋钮、滚轮或聚焦后用方向键切换电台；RADIO 开关，音量单独调节。
- 录音使用 MediaRecorder，解码、回放、实时电平与走带音效使用 Web Audio API。

电台使用公开 CNR HLS 或 MP3 地址，失败/超时自动切换下一路，全部失败后停止尝试。播放通过原生 audio 进行，不把跨域电台接入 Web Audio，避免 CORS 导致静音。地址及跨域策略由第三方控制，未能在此环境联网核实可用性；显示的 MHz 为复古调谐参考值，并非网络流的实际频率。当前为单可视磁带仓搭配 Deck B 电台面板。

验证：Chromium 模拟麦克风完成录制、保存、播放、暂停、变速、循环、叠加和键盘调谐检查；无页面脚本错误。未验证真实麦克风、真实电台播放和完整 10 分钟录制。
