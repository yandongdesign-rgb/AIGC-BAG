# 弦光指挥台

手势交互音乐视觉系统：摄像头识别手部关键点，挥拍、高度、速度、开合映射为节拍、音高与音色，WebGL 粒子、拖尾与花朵随频谱联动。支持交响与电子两种风格。

## 运行

单文件，无需构建。用 Chrome 桌面端打开 `index.html` 并允许摄像头；若直接打开拿不到权限：

```
python -m http.server
```

然后访问 `http://localhost:8000/gesture-maestro/`。手部模型（MediaPipe Hands）首次启动时联网加载。

## 操作

- 挥拍：手向下一顿即一拍
- 高度与速度：音高、音区与力度
- 开合：握拳、半开、张开切换三种音色
- 另一只手：高度选和弦，开合控制厚度；双手合拢停留切换风格
- 快捷键：S 风格，C 摄像头画面，F 全屏，M 静音，Q 精度，H 说明

没有摄像头时可点「用鼠标试玩」。
