# 脉冲秀场 Pulse Runway

一个时尚动感的音乐网页：全部声音由 Web Audio API 实时合成，画面由 Canvas 跟随音乐实时绘制。

- **三个场景**：RUNWAY（秀场浩室 124 BPM）、NEON DRIFT（霓虹合成器浪潮 104 BPM）、AFTERHOURS（深夜科技 128 BPM）
- **16 步鼓机**：点击格子编辑底鼓 / 拍手 / 踩镲
- **打击垫**：键盘 A–K 现场触发底鼓、拍手、开镲、和弦、上升、镭射、坠落、扫频
- **调音台**：速度、滤波、摇摆、音量
- **视觉模式**：光环 / 地平线 / 隧道
- **载入自己的音乐**：本地音频文件，画面随低频自动打拍

## 打开方式

直接用浏览器打开 `music-pulse/index.html`（iPad 的 Safari 也可以），无需安装依赖。

快捷键：空格 播放/暂停 · A–K 打击垫 · 1–3 切换场景。

`pulse-runway.html` 是同一页面的片段版本，用于发布到 claude.ai Artifact。
