# 花语 · 手势花园 (Gesture Garden)

用摄像头和 MediaPipe Hands 识别手势，控制一座程序绘制的疗愈花园：

| 手势 | 效果 |
| --- | --- |
| ✋ 张开手掌 | 茎叶从中间向两侧依次长出，花苞绽放，飘起花粉光点，风铃声变得更密 |
| ✊ 握拳 | 默认是**收拢**：花瓣马上合起，飘落几片花瓣，植株慢慢缩回土里。可切换为**暂停** |
| 手放下 / 其他手势 | 时间静止，植物只随风轻轻摆动 |

背景音乐是 Web Audio 实时生成的舒缓纯音乐（柔和和弦 Pad + 五声音阶风铃 + 风声 + 混响），会一直循环，不需要音频文件。

## 运行

**双击 `index.html` 就能运行**，不需要构建，也不需要 Node。

- 推荐使用最新版 **Chrome / Edge**（`file://` 页面可以申请摄像头权限）。
- 第一次运行需要联网，从 `cdn.jsdelivr.net` 加载 MediaPipe 模型（约 10MB），之后浏览器会缓存。
- 如果你的浏览器不允许在 `file://` 下使用摄像头（比如部分 Safari 版本），可以在本目录起一个本地服务：
  ```bash
  python3 -m http.server 8080   # 然后打开 http://localhost:8080
  ```
- 没有摄像头时，可以点「无摄像头 · 键盘演示」进入演示模式。

### 快捷键

| 键 | 功能 |
| --- | --- |
| `↑`（按住） | 模拟张开手掌 |
| `↓`（按住） | 模拟握拳 |
| `F` / 双击画面 | 全屏 |
| `M` | 音乐开关（鼠标悬停在音乐按钮上可以调音量） |
| `G` | 切换握拳行为：收拢 / 暂停 |
| `V` | 显示 / 隐藏摄像头预览 |
| `H` | 禅模式，隐藏全部界面 |

全屏展示时，鼠标 3.5 秒不动，指针和按钮会自动隐藏。

## 延迟设计（目标 < 200ms）

| 环节 | 做法 | 典型耗时（桌面端） |
| --- | --- | --- |
| 采集 | 640×480 @30fps；用 `requestVideoFrameCallback` 在新帧到达时立刻送去识别 | 帧间隔 ≤ 33ms |
| 推理 | 用 Lite 模型（`modelComplexity: 0`），只识别单手，GPU 推理；上一帧没算完就丢掉新帧，**从不排队** | 约 10–30ms |
| 判定 | 根据关键点几何关系分类，连续 **2 帧**一致才确认 | 约 33ms |
| 反馈 | 握拳时花瓣以 1.6/s 的速度收拢，确认后的下一帧（≤ 16ms）就能看到变化 | ≤ 16ms |

合计通常在 **60–100ms**。HUD 左上角会实时显示「识别耗时 · 响应延迟 · 识别帧率」，响应延迟超过 200ms 时数字变成红色。响应延迟的计算方式是：新手势第一次出现的那一帧送去识别的时刻，到手势被确认的时刻。

## 目录结构

```
gesture-garden/
├── index.html        页面结构（HUD、控制栏、预览、开场卡片）
├── css/style.css     低饱和自然风格样式
└── js/
    ├── config.js     所有可调参数：摄像头、模型、防抖、生长速度、色板、音乐
    ├── utils.js      数学、缓动、颜色、可复现随机数
    ├── music.js      AmbientMusic：生成式疗愈音乐（Web Audio）
    ├── plants.js     植物：波斯菊 / 郁金香 / 薰衣草 / 大花葱 / 蕨 / 阔叶 / 草丛
    ├── garden.js     Garden：背景、布局、生长时间轴、粒子
    ├── gesture.js    HandTracker：摄像头、MediaPipe、手势分类与防抖
    └── main.js       入口：把各模块连起来，处理 UI、键盘、全屏和渲染循环
```

脚本都是普通 `<script>`，没有用 ES Module，因为 Chrome 会拦截 `file://` 下的模块加载。所有模块挂在 `window.GG` 下面。

## 自定义

- **调速度**：改 `config.js` 里的 `garden.growSpeed`、`foldSpeed`、`retractSpeed`。
- **握拳默认行为**：`garden.fistMode = 'close' | 'pause'`。
- **用自己的音乐**：把文件放到比如 `assets/music.mp3`，然后设置 `music.customUrl = 'assets/music.mp3'`。
- **改配色**：改 `config.palette`。
